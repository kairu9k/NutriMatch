NutriMatch — logins

The demo data and its seeder were removed on 2026-10-19 (adviser's request): the
database starts with one admin account and real accounts are registered through
the app (Register for clients and RNDs; admins via Users -> Add admin).

ADMIN
  email:    admin@nutrimatch.ph
  password: ask the team lead (not written here — this file is on GitHub)
  sign in:  http://localhost:3000/admin/login

Forgot it? Admin sign-in -> Forgot password (a code is emailed), or on the
backend machine: python manage.py changepassword admin@nutrimatch.ph

New database on another machine:
  cd backend
  python manage.py migrate
  python manage.py seed              # FNRI food exchange list + system settings (reference data, not demo data)
  python manage.py createsuperuser   # the first admin
